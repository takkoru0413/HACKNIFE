# HACKNIFE（ハックナイフ）

**ナイフで戦う 1v1 ゲームの中で、Scratch 風のブロックを組んで「チート」を自作して戦う。**

フライ、ESP、エイムボット、壁抜け、テレポート、キルオーラ……出来合いの能力はひとつもありません。
ゲームの値（座標・速度・向き・重力など）を読み書きするブロックだけを使って、自分の手でチートを作ります。

ただし HP とダメージは「サーバー側の値」なので書き換えられません。数値を盛るのではなく、**移動・視点・情報** で有利を取るチートを工夫するゲームです。

## 遊び方

- 武器はナイフ（ダメージ 5、届く距離 約 2.5m、0.4 秒に 1 回）。HP は 100。
- 操作: **WASD** 移動 / **スペース** ジャンプ / **左クリック** ナイフ / **Esc** ポーズ
- ロビーでホストが対戦設定を決める:
  - ルール: プリセット対戦（作っておいたチートで戦う） / フリー作成対戦（その場で作る）
  - 先取ラウンド数 / セット数 / ラウンド時間 / 作成時間 / 作成タイムを毎セット取るか
- メニューの「練習」で、ボット相手にすぐ試せます。

### チートの作り方

メニューの「能力エディタ」で、ブロックをドラッグしてつなげます。見本（フライ・ESP・エイムボット・壁抜け・キルオーラ・ブリンク攻撃）が入っているので、「開く」で中身を見ると作り方がわかります。

| カテゴリ | できること |
|---|---|
| 自分 | 自分の座標・速度・向きを読む / 書き換える |
| 物理・操作 | 重力・移動速度・ジャンプ力などを変える、壁の当たり判定オン/オフ、ナイフを振る |
| 敵・調べる | 敵の座標・向き・HP、距離、キー入力 |
| 表示 | 壁越しに見える箱や線を描く、画面に数値を出す |
| 演算 | 四則演算、√、sin/cos、角度（atan2） |

## オンライン対戦

### サーバーで遊ぶ
1. メニューの「友達のサーバーで遊ぶ」に、教えてもらったサーバーのアドレス（`IP` または `IP:ポート`）を入れて「接続」。
2. 部屋を作る / 部屋に入る → ロビーで設定して開始。

### 直接つなぐ（サーバーなし）
片方が「部屋を作る」、もう片方が相手の IP を入れて「参加」。

離れた相手とは **Radmin VPN / Tailscale** などで同じネットワークに入るか、**UDP 7777** をポート開放してください。
